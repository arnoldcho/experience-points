# 경험치

커뮤니티에서 시작된 체인이 있었다. 모두가 떠난 뒤에도 한 사람이 남았다.

이 소설은 2017년 겨울부터 2026년까지, 하나의 블록체인 프로젝트를 둘러싼 실화 기반 이야기다. 발견, 팽창, 침묵, 포크, 법인, 붕괴, 생존, 우회, 그리고 두 번째 시작. 한 사람이 체인을 붙잡고 버틴 8년의 기록을 소설의 형태로 담았다.

## 장르

실화 기반 소설 (팩션)

## 서술 방식

3인칭 근접 시점
