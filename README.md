# 경험치

커뮤니티에서 시작된 체인이 있었다. 모두가 떠난 뒤에도 한 사람이 남았다.

---

2017년 겨울, 한 대학원생이 우연히 하나의 암호화폐 프로젝트를 발견한다. 블로그에 글을 쓰고, 사람들이 모이고, 커뮤니티가 폭발한다. 그러나 원래 팀은 침묵하고, 시장은 무너지고, 남은 사람들은 체인을 직접 이어받기로 결심한다.

포크, 법인 설립, 붕괴, 단독 생존, 시장 우회, 그리고 다시 시작.

한 사람이 체인을 붙잡고 버틴 8년의 기록을 소설의 형태로 담았다.

## 작품 정보

- **장르**: 실화 기반 소설 (팩션)
- **서술 방식**: 3인칭 근접 시점
- **시간 범위**: 2017년 겨울 ~ 2026년 봄
- **분량**: 전 10장, 58개 장면
- **저자**: 조이사

## 목차

| 장 | 제목 | 한 줄 |
|----|------|-------|
| 1장 | 발견 | 2017년 겨울, 모니터 앞에서 하나의 코인을 발견하다 |
| 2장 | 커뮤니티의 팽창 | 사람이 몰려왔고, 설명하는 사람의 자리가 바뀌기 시작했다 |
| 3장 | 침묵 | 숫자가 가장 뜨거운 순간에, 안쪽에서 설명이 사라졌다 |
| 4장 | 포크의 결심 | 기다림이 끝나고, 남은 사람들이 직접 움직이기로 했다 |
| 5장 | 이름을 정하다 | 코드보다 먼저, 부를 수 있는 이름이 필요했다 |
| 6장 | 한국 법인 | 체인이 사무실과 계약서와 월급의 세계로 내려왔다 |
| 7장 | 붕괴 | 누구도 완전히 틀리지 않았기 때문에 무너졌다 |
| 8장 | 단독 생존 | 체인을 키우는 사람이 아니라, 지워지지 않게 만드는 사람 |
| 9장 | 시장의 우회 | 정면이 막혀 있을 때, 사람은 우회로를 찾는다 |
| 10장 | 두 번째 시작 | 이번에는 자기 손으로 문을 세우는 일이었다 |

## 읽기 전에

이 소설은 실제 블록체인 프로젝트를 바탕으로 한 팩션(faction)입니다. 등장하는 인물, 프로젝트, 기관의 이름은 모두 가명으로 처리되어 있습니다. 실존 인물 및 단체와의 직접적인 연관은 없습니다.
